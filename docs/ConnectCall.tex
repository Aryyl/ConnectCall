\noindent
ConnectCall is a modern, real-time audio and video calling Flutter application. It features a sleek Material 3 user interface, persistent background calling capabilities, and robust user management. The app is designed to deliver a seamless communication experience with offline push notifications, allowing devices to ring even when the app is asleep or killed.
\vspace{1em}

\section*{Features}
\begin{itemize}
    \item \textbf{Real-Time Communication:} 1-on-1 and Group Audio/Video calling.
    \item \textbf{Offline Push Notifications:} Calls ring on the receiver's device even if the app is killed, using ZPNs (ZEGOCLOUD Push Notification service).
    \item \textbf{Screen Sharing:} \textit{(Currently experiencing issues)} Built-in screen sharing capabilities utilizing the gallery layout.
    \item \textbf{User Authentication:} Secure user authentication managed via Firebase Auth.
    \item \textbf{User Management \& Blocking:} A robust user directory allowing you to block/unblock users to prevent unwanted calls.
    \item \textbf{Call History:} Automatic logging of incoming, outgoing, missed, and rejected calls synced in real-time.
    \item \textbf{Automated Permissions:} Clean, sequential permission request flow (Camera, Mic, Notifications, Display Over Other Apps) on first launch to ensure smooth call connections.
\end{itemize}

\section*{Tech Stack \& Architecture}
\begin{itemize}
    \item \textbf{Flutter Version:} Flutter 3.24+
    \item \textbf{Architecture:} Feature-first modular architecture utilizing Controller/Service patterns.
    \item \textbf{State Management:} \texttt{flutter\_riverpod} (v2) for reactive, compile-safe state management.
    \item \textbf{Routing:} \texttt{go\_router} featuring a persistent bottom navigation shell (\texttt{StatefulShellRoute}).
    \item \textbf{Backend:} Firebase 
    \begin{itemize}
        \item \textit{Firebase Auth} for identity.
        \item \textit{Cloud Firestore} for user directories, blocking logic, and call history.
    \end{itemize}
    \item \textbf{Calling SDK:} ZEGOCLOUD
    \begin{itemize}
        \item \texttt{zego\_uikit\_prebuilt\_call} for the core calling UI and WebRTC engine.
        \item \texttt{zego\_uikit\_signaling\_plugin} \& \texttt{zego\_zpns} for offline call invitations and push notifications.
    \end{itemize}
\end{itemize}

\section*{Setup Instructions}

\subsection*{Prerequisites}
\begin{enumerate}
    \item \textbf{Flutter SDK} installed and configured on your machine.
    \item A \textbf{Firebase Project} with Authentication (Email/Password) and Firestore enabled.
    \item A \textbf{ZEGOCLOUD account} with a registered project to obtain your App ID and App Sign.
\end{enumerate}

\subsection*{1. Clone \& Install Dependencies}
\begin{verbatim}
git clone <repository_url>
cd connect_call
flutter pub get
\end{verbatim}

\subsection*{2. Firebase Configuration}
\begin{itemize}
    \item Download your \texttt{google-services.json} from the Firebase Console.
    \item Place it inside the \texttt{android/app/} directory.
    \item \textit{(For iOS, place the \texttt{GoogleService-Info.plist} inside the \texttt{ios/Runner/} directory).}
\end{itemize}

\subsection*{3. Environment Variables (.env)}
The app uses \texttt{flutter\_dotenv} to securely manage ZEGOCLOUD credentials. Create a \texttt{.env} file in the root directory (\texttt{connect\_call/.env}) and add your ZEGOCLOUD credentials:

\begin{verbatim}
ZEGO_APP_ID=1234567890
ZEGO_APP_SIGN=your_64_character_hex_string_here
\end{verbatim}

\textit{Ensure that \texttt{.env} is declared in your \texttt{pubspec.yaml} under the \texttt{assets:} section.}

\subsection*{4. Run the App}
To test audio/video capabilities and offline push notifications, it is highly recommended to run the app on \textbf{physical devices} rather than emulators.

\begin{verbatim}
flutter run
\end{verbatim}

\section*{Known Limitations}
\begin{enumerate}
    \item \textbf{Simulator/Emulator Constraints:} Audio, Video, and Push Notifications behave unreliably on emulators. Always test on physical devices.
    \item \textbf{iOS Background Calling:} Offline push notifications on iOS require additional configuration (APNs certificates) in the ZEGOCLOUD console and Apple Developer Portal.
    \item \textbf{Android 14+ Permissions:} The app requests \texttt{USE\_FULL\_SCREEN\_INTENT} and \texttt{SYSTEM\_ALERT\_WINDOW} explicitly. Depending on the Android manufacturer (e.g., Xiaomi, Vivo), the user may still need to manually allow "Display pop-up windows while running in the background" in the OS settings.
    \item \textbf{Network Sensitivity \& Stability:} The underlying calling technology is highly sensitive to network fluctuations. Poor or unstable internet connections can cause calling screen glitches, delayed connections, or dropped calls.
\end{enumerate}
